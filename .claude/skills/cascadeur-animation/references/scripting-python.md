## Quy trình: Can thiệp Hoạt cảnh bằng Modify Methods
1. Định nghĩa hàm callback nhận các tham số `model_editor`, `update_editor`, `scene_updator` [K61 4:33 "will always be model editor and the update editor in the case"].
2. Lấy các editor chuyên biệt từ model editor: `data_editor = model_editor.data_editor()` và `layers_editor = model_editor.layers_editor()` [K61 4:46 "the editors we already have the model editor and we can access"] [K61 8:40 "as before this is accessible through the model editor in our modifier"].
3. Xác định track/layer của đối tượng bằng `layer_id = scene.layers_viewer().layer_id_by_obj_id(object_id)` [K61 8:14 "specific specifically the layer viewer from the domain scene"].
4. Đặt keyframe trên layer hoạt cảnh bằng phương thức thiết lập keyframe trên `layers_editor` [K61 8:40 "setting the key on this layer we are modifying the scen so"] [K61 8:55 "how it works first provide the layer ID which we got previously"].
5. Nếu mở rộng phạm vi hoạt cảnh sang khung hình mới, gọi `model_editor.fit_animation_size_by_layers()` để khớp độ dài dải animation [K61 10:27 "on discard I found that we can extend the animation range inside"].
6. Thiết lập toạ độ vị trí mới thông qua phương thức `set_data_value` của `data_editor` kết hợp với thư viện `numpy` [K61 5:15 "method provided by the data editor like so so let's call this"] [K61 6:12 "3x1 matrix and to create such a matrix with numpy first we"].
7. Cập nhật dữ liệu vào scene bằng `scene_updator.run_update({pos_data_id}, frame)` [K61 7:09 "scene updator that run update in our case we only need to"].
8. Kích hoạt phiên can thiệp trên scene: `scene.modify_update("Move Cube", move_cube)` [K61 4:33 "of the modify update method the third argument is the scene updator"]. Giữ số lần gọi modify methods ở mức tối thiểu để bảo toàn hiệu năng lưu lịch sử [K61 13:24 "number of calls to modify methods because each call saves the scene"].

## Quy trình: Sử dụng Kịch bản Add Noise (Animation Scripts)
1. Chọn khoảng khung hình cần tác động trên timeline và quét chọn các Point Controller (ví dụ: khớp bàn tay) hoặc Camera [K11 1:02 "First, select the desired time range and then select the point controllers you want to affect"] [K11 3:12 "Now I can take you to my next point"].
2. Vào menu **Commands → Animation Scripts → Add noise to selected objects** [K11 1:02 "Next, go to Commands -> Animation Scripts -> Add noise to selected objects"].
3. Chọn chế độ rung: Mode 1 (tất cả đối tượng rung giống hệt nhau) hoặc Mode 2 (mỗi đối tượng rung độc lập ngẫu nhiên, tự nhiên hơn) [K11 1:19 "In the first mode, the selected controllers or objects will receive the same noise"].
4. Thiết lập hệ toạ độ Object Space: chọn True để áp dụng toạ độ toàn cục (Global) cho point controllers [K11 1:34 "In this case, we'll leave the global mode enabled because point controllers do not support local transformation nodes"].
5. Cài đặt giới hạn biên độ (limits): đặt khoảng 0.15 cho rung nhẹ bàn tay [K11 1:52 "These upper and lower limits define the maximum and minimum range of the movement"]; đặt từ 6 đến 8 cho rung lắc camera [K11 3:26 "For camera shake, values between six and eight usually work well"].
6. Chọn trục rung lắc (XYZ cho chi cơ thể; chỉ chọn trục Y cho camera nếu muốn tránh lệch hướng chuyển động chính) [K11 2:09 "For the axes parameter, we'll use XYZ, so the effect applies to all axes"] [K11 4:48 "In the axes selection, we're going to omit Z to avoid disrupting the main motion"].
7. Để tạo hiệu ứng máy quay cầm tay sống động (Live Camera): đặt keyframe cách nhau khoảng 20 frame, áp dụng noise, sau đó chuyển sang nội suy Bezier [K11 4:33 "We set keys with linear interpolation and intervals of about 20 frames"].
